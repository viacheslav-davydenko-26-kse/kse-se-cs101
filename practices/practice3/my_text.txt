# Загальне
Програмування — це опис алгоритмів на правильному рівні абстракції.
Algorithm — послідовність кроків для розв’язання задачі.
Abstraction — вміння приховати зайві деталі й працювати з головним.

Python - інтерпретована мова програмування

Явне - int(); float(); str()
Неявне - 5 + 2.0; 
# Алгоритми
Хороший алгоритм має бути:
Clear — кожен крок зрозумілий.
Finite — алгоритм колись завершується.
Executable — кожен крок реально виконати.
Input → Output — алгоритм щось отримує і щось повертає.
# Абстракція
Abstraction — це спосіб дивитися на складну систему, ігноруючи деталі, які
зараз неважливі.

# Типи даних
В Python існує 5 основних типів даних:
• int - Цілі числа без дробової частини. Наприклад: 5, -42, 0
• float - Числа з десятковою частиною. Наприклад: 3.14, -0.01, 2.0
• str - Послідовність символів, укладених у лапки. Наприклад: "Привіт",
'Python', "123"
• bool - Логічне значення: Істина або Хиба. Значення: True, False
• NoneType - Особливе значення, яке означає "нічого". Значення : None

# Змінні
Змінна — це іменований контейнер, у якому зберігається певне значення,
яке може змінюватись у процесі виконання програми.
Іншими словами, змінна дозволяє "дати ім’я" числу, тексту або будь-якому
іншому об'єкту, щоб з ним можна було працювати зручно та зрозуміло.

## Конвенція
Ім’я змінної має бути зрозумілим і логічним.
• Краще писати: price_per_unit, user_age, а не x1, asd, t2.
• Python чутливий до регістру: Age ≠ age.
• Ім’я змінної:
• не може починатися з цифри
• не може містити пробілів або спецсимволів (-, @, %)
• не повинно збігатися з зарезервованими словами (if, def, class, True, None,
тощо)
• Краще використовувати snake_case стиль найменувань:
• Слова розділяються нижніми підкресленнями
• Усе пишеться маленькими літерами

# Дії зі змінними
Зі змінними, яким присвоєно текстові дані, можна робити наступні речі:
1. Конкатинація – об’єднання декількох текстів в один;
2. Мультиплікація – повторювати один і той же текст багато разів;
3. Форматування – вставити в текст змінну.

Конкатинація – виконується за домогою знака «+» між текстами
Мультплікація – виконується за домогою знака «\*»між текстом і числом
Форматування – вставлення змінної в текст.
Виконувати за допомого:
1. “f-string”
2. Методy .format()
